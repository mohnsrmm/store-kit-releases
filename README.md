# Store Kit — releases

Windows app that turns a Flutter / Android project folder plus emulator screenshots into a complete Google Play listing kit: styled phone and tablet screenshots, the 512 icon and the 1024×500 feature graphic — every file checked against the Play Console rules before it is written.

- Product page, screenshots and pricing: https://www.nasrtech.dev/store-kit/
- Download: the latest zip under **Releases** (Windows 10/11 x64 — unzip and run `store_kit.exe`)
- Free to try; exporting the files needs a one-time licence key
- Support: support@nasrtech.dev

This repository only hosts the release builds. No source code here.
